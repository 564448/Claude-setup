It is the user-scoped MCP server `kicad`, installed at `Project/tools/kicad-mcp`, and needs the IPC API server enabled and a pinned Python 3.12 `uv` env, because Python 3.14 has no `pynng` wheel yet. The pipeline was written after the CanSat carrier board (`Project/SPACE/Cansat/hardware2`, 4-layer, DRC 0/0). SKILL.md carries the full failure catalogue (units, mirror conventions, GND-island dead ends on 2 layers, SWIG pitfalls). Scripts are in `scripts/`; Freerouting + JRE live in `tools/` (git-ignored; see `tools/README.txt`). The KiCad-8 workarounds are not yet re-verified on KiCad 9.
